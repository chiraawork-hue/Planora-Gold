# Planora Gold 

**Your Private Gold Collection** — personal physical-gold portfolio tracker.

A mobile-first single-file application using HTML, CSS and vanilla JavaScript, with no dependencies or build step.

## Features
- Dashboard: total physical gold, number of bars, purchase costs and estimated buyback value where quotes exist
- Gold gallery: record individual Antam, UBS, Lotus and EMASKU (Hartadinata) bars
- Gold details and delete
- Manually record buyback quotes for an exact brand and weight, with date
- Historical chart and price movement only when comparable dated quotes are available
- Browser localStorage persistence

## Privacy & accuracy
The repository is public, but users' collection entries and price notes are saved in the **browser's localStorage**, not committed to GitHub. Local data is not synchronized between browsers/devices and may disappear if browser site data is cleared. Back up important records independently.

Automatic buyback updates are **not implemented**. The app does not invent daily prices or infer daily changes where date-specific comparable records are absent. Generic bar shapes in the interface are **illustrations**, not official product photos.
